# 电池模组装配基地 · 数字孪生

Three.js r168 程序化建模的工业数字孪生：基地总览（厂房、道路、仓储、港口）+
产线工序仿真（机械臂、检测工位、AGV 车辆、船舶调度、物料协同）+ 自动巡游。
白灰 + 工业橙配色，轻量悬浮数据面板。纯静态站点，**零构建、零 npm 依赖**，
Three.js 本地自包含于 `vendor/`，不依赖任何公网 CDN。

## 本地预览

必须通过 HTTP 服务预览（ES Module 不能用 `file://` 双击打开）：

```bash
python -m http.server 8080
```

浏览器打开 <http://localhost:8080>。

## 功能

- **基地总览**：程序化厂房 / 仓储堆棚 / 港口码头，路网节点图生成主干道与支路
- **机械臂工作站 ×2（P1）**：等待 → 抓取 → 搬运 → 落位 → 回位 事件门控五阶段
  状态机；圆柱坐标轨迹 + 二连杆 IK；夹爪与工件 `Object3D.attach()` 挂接
- **检测工位（P2）**：夹紧 → 探针接触 → 检测中 → 结果反馈；指示灯状态联动，
  确定性 NG 序列，面板推算良率
- **AGV 车队 ×5（P2）**：沿路网弧长行驶、右侧行车道、跟车间距、路口占用锁、
  故障停车与警报联动
- **船舶调度与港口装卸（P4）**：班轮 A/B 错峰靠离（班期 6 分钟/轮），进港减速
  靠泊 → STS 岸桥逐箱装卸（堆场箱真实移至甲板，随船出港）→ 回转满载离港
- **物料协同（P4）**：2 条物料 AGV 线执行工件级任务队列 —— 仓储装料 → 工位
  卸料/收成品 → 交检测 → 回仓；料空/成品满时机械臂自动待料/阻塞（队列推拉）
- **自动巡游（P3）**：9 站镜头序列，鼠标拖拽即接管
- **交互**：点击任一设施（含班轮/岸桥）高亮 + 平滑聚焦 + 面板信息；暂停/恢复
  （所有工序动画基于全局仿真时钟，暂停停走、恢复连续无跳变）

## 部署（EdgeOne Pages）

1. 推送本仓库到 GitHub：<https://github.com/ChenYi1031/digitaltwin.git>
2. EdgeOne Pages →「导入 Git 仓库」→ 选择仓库
3. 构建命令、安装命令、输出目录**全部留空**（根目录 `edgeone.json` 已声明零构建）
4. 无需任何环境变量

## 目录结构

```
index.html            页面入口（importmap 指向本地 vendor）
edgeone.json          零构建静态站点声明
css/main.v2.css       悬浮面板样式
js/main.v3.js         入口：装配模块、渲染循环
js/config.v3.js       全局常量：尺度、颜色、路网、班期与工序参数
js/scene.v3.js        场景、相机、灯光、天空渐变
js/factory.v3.js      厂房 / 装配试验区 / 仓储 / 港口（堆场 yardAPI）
js/road.v3.js         路网节点图 → 路面与标线
js/robot.v3.js        机械臂事件门控五阶段状态机（P1/P4 队列门控）
js/inspection.v3.js   检测工位四阶段（P2）
js/vehicle.v3.js      AGV 车队沿路网行驶（P2，跨系统避障接口）
js/marine.v3.js       船舶靠离调度 + STS 岸桥装卸（P4）
js/material.v3.js     物料 AGV 工件级任务队列（P4）
js/camera.v3.js       OrbitControls + 缓动聚焦 + 自动巡游（P3）
js/interaction.v3.js  Raycaster 拾取与高亮
js/ui.v3.js           悬浮面板逻辑
js/simClock.v2.js     全局唯一仿真时钟
vendor/               Three.js r168 本地自包含
```

## 缓存策略

静态资源（JS/CSS）文件名带版本后缀（当前 JS `.v3`）。**内容变更时必须升版本号
并同步更新所有 import 路径与 index.html 引用**，避免 EdgeOne 边缘缓存返回旧版本。
